Controle de Treinamentos

Um site desenvolvido para a Sanofi, projetado para otimizar o controle de treinamento, garantindo uma gestão mais eficiente e organizada das atividades formativas. Essa plataforma visa facilitar o acompanhamento do progresso dos colaboradores, promovendo um ambiente de aprendizado mais eficaz e alinhado às necessidades da empresa.

Link

Visão Geral do Projeto

Desenvolvemos um sistema de controle de treinamentos para a Sanofi, substituindo o método atual de registro em Excel. A solução visa organizar os treinamentos e facilitar a gestão dos colaboradores.

  • Cadastro e Login: Usuários podem se cadastrar e fazer login, com redirecionamento por permissões.
  • Cadastro de Treinamentos: Organizadores podem cadastrar treinamentos facilmente.
  • Relatórios Gráficos: Visualização rápida da presença e ausência dos colaboradores.
  • Tickets de Informação: Detalhes de cada treinamento, incluindo data e lista de ausentes.
  • Acompanhamento do Usuário: Colaboradores acompanham seus treinamentos de forma clara.
  • Registro de Presença: Botão para registrar a presença rapidamente, com verificação automática da data.
  • HTML, CSS e JavaScript: Estrutura, estilo e interatividade do front-end.
  • Python com Flask: Gerenciamento do back-end e comunicação com o banco de dados.
  • Flask-Mail: Envio de e-mails para recuperação de senhas.
  • AWS: Hospedagem do banco de dados MySQL.
  • DBeaver: Gerenciamento de dados no MySQL.
  • VSCode: Editor de código para desenvolvimento.
  • Ngrok: Acesso externo durante o desenvolvimento.
  • Git: Controle de versões do código-fonte.

Acreditamos que a Sanofi terá um controle mais eficaz dos treinamentos, melhorando a experiência dos colaboradores e otimizando o gerenciamento.
