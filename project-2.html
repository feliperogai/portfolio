Pokédex

A Pokedex é meu primeiro projeto de front-end, funcionando como um catálogo interativo de Pokémon. Ela exibe uma lista com imagens e detalhes, como tipos e habilidades. Utilizei HTML, CSS e JavaScript, integrando dados da PokéAPI. O projeto me ensinou sobre manipulação do DOM e integração de APIs, refletindo meu entusiasmo pelo desenvolvimento web e a criação de experiências interativas.

Visão Geral do Projeto

A Pokedex é meu primeiro projeto de front-end, um catálogo interativo de Pokémon que combina design e funcionalidade. Seu objetivo é criar uma interface amigável para os amantes de Pokémon, permitindo explorar e aprender sobre suas criaturas favoritas.

Funcionalidades incluem: Listagem de Pokémon com imagens detalhadas. Detalhes acessíveis ao clicar em um Pokémon, como tipos e habilidades. Filtro de Pesquisa para buscar por nome ou tipo. Sistema de Favoritos para criar uma lista personalizada.

Tecnologias Utilizadas: HTML para estrutura semântica. CSS com Flexbox e Grid para um layout responsivo. JavaScript para interatividade e manipulação do DOM. PokéAPI para dados atualizados sobre Pokémon.

Este projeto foi uma importante oportunidade de aprendizado, melhorando minhas habilidades em programação e despertando uma paixão por desenvolvimento web.
